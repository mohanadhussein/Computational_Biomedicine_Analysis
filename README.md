# Computational Biomedicine Analysis
A repo that lists implementation examples/tutorials of various Omics Analysis in R based on the [Computational Genomics in R](https://compgenomr.github.io/book/) book. 
Each page includes a single tutorial written as Rmd report and rendered as an HTML file with the link attached here.
Additions and corrections to some mistakes I noticed in the tutorials are included. More to follow!!
