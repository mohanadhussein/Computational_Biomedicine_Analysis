# Computational Biomedicine Analysis
A repo that lists implementation Examples/Tutorials of various Omics Analysis in R based on the [Computational Genomics in R](https://compgenomr.github.io/book/) book. 
Each page includes a single tutorial written as qmd report and rendered as an HTML file with the link attached here.
In the attAdditions and corrections to some mistakes I noticed in the tutorials are included.
